# ReQuest

Сайт-кабинет преподавателя и его учеников: регистрация, приём заявок, профили учеников, цена и реквизиты для оплаты. Следующие этапы добавят календарь с записью, задания, библиотеку, оплаты, карточки и тренажёры каны — они уже работают в прототипе.

## Установка на сервер

Нужен сервер с Ubuntu 22.04 или 24.04 (2 ядра, 2–4 ГБ памяти) и домен.

1. Откройте веб-консоль сервера в панели хостинга (вход под `root`).
2. Вставьте одну команду и отвечайте на вопросы:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/makaba-oss/request/main/scripts/install.sh | bash
   ```
3. В панели регистратора домена создайте A-записи `ваш-домен` и `www.ваш-домен` на IP сервера (скрипт покажет его в конце).
4. Через 5–30 минут откройте `https://ваш-домен` и войдите с почтой преподавателя.

Скрипт ставит Docker, скачивает код в `/opt/request`, создаёт `.env` с паролями и запускает четыре контейнера: сайт, базу PostgreSQL, Caddy (HTTPS выпускается автоматически) и ежедневную копию базы в `backups/` (хранится 14 дней).

## Почта для кодов входа

Вход — по коду из письма. Пока почта не настроена (`SMTP_URL` пустой), коды видны в журнале: `docker compose logs app`.

Чтобы письма уходили по-настоящему, впишите в `/opt/request/.env` строку `SMTP_URL` и перезапустите: `docker compose up -d`. Пример для Яндекс 360 (нужен пароль приложения):

```
SMTP_URL=smtps://no-reply%40ваш-домен.ru:ПАРОЛЬ@smtp.yandex.ru:465
```

`@` в логине записывается как `%40`.

## Обновление

```bash
cd /opt/request && git pull && docker compose up -d --build
```

## Восстановление базы из копии

```bash
cd /opt/request
gunzip -c backups/request-ГГГГ-ММ-ДД.sql.gz | docker compose exec -T db psql -U request request
```

## Разработка

```bash
npm ci
cp .env.example .env   # DATABASE_URL на локальную базу PostgreSQL
npm run db:migrate
npm run dev
```

Миграции — обычные SQL-файлы в `db/migrations`, применяются по порядку при каждом запуске контейнера.
